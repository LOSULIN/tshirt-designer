# 模特模板素材規格

將正式 PNG 放入此資料夾後，設計器會自動載入。檔名必須與下方清單**完全一致**。

## 必要檔案（共 8 張）

| 檔名 | 用途 |
|------|------|
| `adult-male-front.png` | 成人男性正面 |
| `adult-male-back.png` | 成人男性背面 |
| `adult-female-front.png` | 成人女性正面 |
| `adult-female-back.png` | 成人女性背面 |
| `child-male-front.png` | 孩童男生正面 |
| `child-male-back.png` | 孩童男生背面 |
| `child-female-front.png` | 孩童女生正面 |
| `child-female-back.png` | 孩童女生背面 |

## 圖片規格

| 項目 | 數值 |
|------|------|
| 尺寸 | **1024 × 1536 px**（寬 × 高） |
| 格式 | **PNG**（請勿將 JPEG 僅改副檔名為 `.png`） |
| 色彩 | sRGB |
| 背景 | 建議純色或簡潔背景，模特置中 |
| 衣服 | 建議**白色或淺色**素 T，方便預覽設計 |

## 印刷區對位（最重要）

設計器會依模特類型自動切換印刷區（`lib/print-area.ts` → `PRINT_AREA_CONFIG`）：

| 模板 | 領口下 | 最大印刷 | 輸出 px @300DPI | 畫布印刷區 (w×h @ y) |
|------|--------|----------|-----------------|----------------------|
| 成人男 | 6.5cm | 32×40cm | 3779×4724 | 420×525 @ y=300 |
| 成人女 | 6cm | 28.16×35.2cm (−12%) | 3326×4157 | 370×462 @ y=277 |
| 孩童男/女 | 5cm | 24×30cm | 2835×3543 | 315×394 @ y=231 |

畫布固定 **1024×1536 px**，安全區為各印刷區內縮 5%。

製作模板時，請確保**模特胸前／背部的可印刷範圍**與對應性別的區域對齊。  
若偏移，可微調拍攝構圖，或調整 `PRINT_AREA_CONFIG`。

對位檢查方式：

1. 放入 PNG 後執行 `npm run check:templates` 確認尺寸
2. 開啟設計器，上傳測試圖，確認設計是否落在胸口正確位置
3. 使用「設計瀏覽」確認模特校稿效果

## 平面衣服素材（選用，非模特）

若需「衣服瀏覽」使用真實平面素材，另備正面／背面 PNG，並在 `lib/constants.ts` 的 `FLAT_SHIRT_TEMPLATES` 填入路徑。

## 常見問題

**目前素材是 687×1024？**  
請在影像軟體中調整為 **1024×1536**（可等比放大後上下補白，或重新構圖拍攝），否則設計區藍框與模特胸口可能對不齊。

**副檔名是 .png 但實際是 JPEG？**  
瀏覽器多半仍能顯示，但建議「另存新檔」為真正的 PNG，以利印刷與長期維護。

## 驗證指令

```bash
npm run check:templates
```

全部通過後即可部署上線。
